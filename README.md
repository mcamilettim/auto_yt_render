# auto_yt_render
Render 3D (Blender 4.0.2, Eevee en CPU) de las historias de Hidden Origins.
Este repo es público a propósito: solo tiene código de render. No contiene secretos ni estado.

## Benchmark
Actions → bench → Run workflow. El resumen del run muestra `s_por_cuadro`; el artefacto trae el mp4 y el log.
